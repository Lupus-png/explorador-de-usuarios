# Explorador de Usuários

Aplicação web desenvolvida com HTML, CSS e JavaScript para consultar e explorar usuários por meio de uma API.

**[Acessar aplicação](https://lupus-png.github.io/explorador-de-usuarios/)** · **[Ver código-fonte](https://github.com/Lupus-png/explorador-de-usuarios)**

## Funcionalidades

- Listagem de usuários com nome, username, e-mail, cidade e empresa.
- Busca por nome ou username.
- Filtro de usuários por cidade.
- Combinação dos filtros de busca e cidade.
- Ordenação alfabética crescente (A–Z) e decrescente (Z–A).
- Contadores de usuários totais e resultados encontrados.
- Tratamento de erros durante a requisição à API.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSONPlaceholder

## API

Os dados são obtidos por meio da API de demonstração [JSONPlaceholder](https://jsonplaceholder.typicode.com/users).

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.

É necessária uma conexão com a internet para carregar os dados da API.

## Aprendizados

Este projeto foi desenvolvido para praticar o consumo de APIs com `fetch` e `async/await`, o tratamento de erros com `try/catch`, a manipulação do DOM, os métodos de arrays e a aplicação conjunta de filtros e ordenação.
